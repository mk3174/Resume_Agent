Architected a custom Transformer-based LLM using nanoGPT from scratch as part of The Build Fellowship. Executed PyTorch training loops with hyperparameter tuning, achieving a ~23% reduction in cross-entropy loss over 60k training steps through learning-rate decay scheduling and weight-initialisation tuning.

Engineered a data preprocessing pipeline with custom tokenization for unstructured datasets, cutting data preparation time by ~60%. Layered Hugging Face NLP models on top for structured text generation with automated model evaluation gates.
